# API Error Codes V0.1

API 响应同时使用合理的 HTTP 状态码与业务 `code`，不会把所有错误伪装为 HTTP 200。

| API code | HTTP | 含义 |
|---|---:|---|
| 0 | 200/201 | 成功 |
| 40001 | 422 | 请求参数校验失败 |
| 40002 | 400 | 业务规则不满足 |
| 40101 | 401 | JWT 无效或过期 |
| 40102 | 401 | JWT 已注销 |
| 40103 | 401 | 账号不存在或已停用 |
| 40104 | 401 | 用户名或密码错误 |
| 40301 | 403 | 缺少所需系统角色 |
| 40302 | 403 | 缺少目标社团的 R02 权限 |
| 40401 | 404 | 资源不存在 |
| 40901 | 409 | 当前状态不允许该操作 |
| 40902 | 409 | 重复提交或唯一性冲突 |
| 50000 | 500 | 未预期服务端错误 |
| 50001 | 503 | 数据库暂不可用 |
| 50101 | 501 | V0.1 仅提供路由 Skeleton，业务尚未实现 |

失败格式：

```json
{"code": 40302, "message": "没有该社团的 R02 权限", "data": null}
```

参数校验错误的 `data` 可包含字段级错误数组；500 响应不得回传堆栈、密码或数据库连接信息。
